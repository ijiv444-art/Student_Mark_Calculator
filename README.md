# **STUDENT MARK CALCULATOR**

A python based application designed to calculate student academic performance by evaluating subject wise marks, total marks, percentage, grades, and pass/fail status.

## Project Review
The Student mark calculator is a beginner friendly python project that automates the process of calculating student's results. It accepts marks for five subjects, validate user input, calculates academic performance, and generates a formatted student report.

I developed this project to practice Python programming and understand how programming concepts are used in a real application.

## Features 
    -Student Information: Accepts the Student's name.
    -Subject-wise Marks: Takes mark for python, Java, English, Mathematics, and Physics.
    -Input Validation: Ensures marks are within the range of 0 to 100.
    -Exception Handling: Handles invalid text input using try-except.
    -Automatic Calculation: Calculates total marks and percentage.
    -Grade Evaluation: Assigns grades based on percentage.
    -Pass/Fail Evaluation: Checks whether the student has passed all five subjects.
    -Formatted Report: Displays a clear academic performance report.

## Installation and Execution
Prerequisites: Python 3 installed on your system.

    1. Clone or download this repository.
    2. Open the project folder in VScode.
    3. Open the terminal.
    4. Execute the following command: python main.py
    5. Enter the student name and subject marks when prompted.
    6. View the generated student report.
